# Changelog

## v3.0: Stage 3 final (25 November 2026)

Driven by the Stage 2 teacher feedback: *"no markdown snapshot; the content coverage is insufficient and there are no images/figures/illustrations"* (Markdown V2.0, 18/30), *"both the coverage and learning design are insufficient; there are no images/figures in the guide"* (Study Guide V1.0, 48/60), and the general feedback on coverage, visuals, activities, hyperlinks and answer placement.

### Coverage
- **Ch. 1:** new sections 1.2 *A short history of AI* (timeline 1950–2025) and an AI ⊃ ML ⊃ DL diagram; impact section rewritten as a benefit/risk table, with a worked example on how bias gets in.
- **Ch. 2:** new 2.1 *Data: what the computer actually sees*, 2.3 *Three ways machines learn* (supervised, unsupervised, reinforcement) and 2.4 *Training, testing and overfitting*.
- **Ch. 3:** new 3.2 *Types by functionality* (reactive, limited memory, theory of mind, self-aware).
- **Ch. 4:** new 4.4 *Language AI* (NLP and generative AI); real computer-vision demonstration.
- **Ch. 5:** new 5.1 diagram contrasting rules→answers with data+answers→rules; new 5.3 *The black box problem*; hybrid-design discussion.
- **Ch. 6:** forward-chaining worked example; new 6.2 *Prolog: a language for rules*.
- **Ch. 7:** new 7.2 worked neuron calculation, 7.4 *How does a network learn?* (loss, backpropagation, gradient descent, learning rate), 7.6 four network families with a figure.
- **Ch. 8:** new 8.2 RL vocabulary table, 8.3 expected-value worked example with simulation, 8.4 *Q-learning*, 8.5 *Minecraft diamonds case study* (OpenAI VPT 2022, DeepMind DreamerV3 2025), module wrap-up.
- New *Start Here* page (learners, prerequisites, 8 learning outcomes, route, toolkit, chapter map) and a 42-term glossary.

### Figures and media
- 22 new teaching figures (generated by `tools/make_figures.py`), 11 AI Lab screenshots and 5 TensorFlow Playground screenshots from real runs, all light theme, all captioned and numbered.
- New team mascot "Max the Agent" and the CSMAXXXING logo used across every resource.

### Activities
- Replaced the paper-only activities with the **CSMAXXXING AI Lab** (`activities/ai-lab/index.html`): one interactive, offline mission per chapter with instant explained feedback, including a real Prolog engine.
- Added Python activities (`activities/code/`) and the Prolog file (`activities/prolog/family.pl`).
- Every lab now follows *predict → try → record → reflect*, with screenshots and hints.
- Answers moved out of the activities into a separate *Answers and feedback* section at the end of each chapter.

### Accuracy and consistency
- Long verbatim source passages in Chapters 1–5 rewritten in our own words, with citations kept.
- Terminology unified across the guide, slides and test bank (for example `aunt_or_uncle`, "Narrow AI (Weak AI)", "Adjustments").
- Every Prolog answer re-checked by running it in Tau Prolog; every Lab 7B and 8 result taken from actual runs.

### Repository
- New README with start point, folder guide, run instructions and limitations; `docs/resource-mapping.md`; rendered PDF in `dist/`; build scripts in `tools/`.
