### 2.1 Input: Data Collection & Categorization
Data Ingestion: The fundamental collection of massive raw information volumes to build machine learning foundations.


Structured Data: Highly organized, indexed files easily parsed in relational setups (e.g., spreadsheets, transaction logs, SQL tables).

Unstructured Data: Unformatted informational inputs making up the bulk of global data (e.g., text blocks, video streams, audio clips, social feeds).

Data Cleaning: Preprocessing steps to eliminate duplicate entries, correct input errors, and resolve missing parameters for baseline data quality.

Labeling/Annotation: Tagging specific target entities within datasets during supervised training so the system learns what it is evaluating.

Feature Extraction: Isolating highly relevant variables within a data pipeline while discarding background noise.
